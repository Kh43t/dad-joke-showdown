Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan.

This program writes one original dad joke to `/output/entry.txt`:

> I asked the salt shaker how it stays calm. It said, 'I'm seasoned — nothing shakes me.'

## Run it

```sh
node main.ts
```
